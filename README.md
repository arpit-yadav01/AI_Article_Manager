# 📝 AI Article Writing Platform

A full-stack AI-powered article writing platform built for learning and student-level use.

## 🚀 Features
- User authentication (JWT)
- Role-based access (User / Admin)
- Article CRUD with ownership rules
- AI-powered features (Admin only):
  - ✨ Summarize articles
  - ✨ Improve writing
  - 🧠 Find mistakes & suggestions

## 🛠 Tech Stack
**Frontend:** React + Vite  
**Backend:** Node.js + Express  
**Database:** MongoDB  
**AI:** Groq (LLaMA 3.1)  

## 🔐 Roles
- **User:** Create & read articles
- **Admin:** Manage any article + AI tools

## 🧪 AI Features
AI features are tested via backend APIs and integrated into UI with proper admin checks.

## 📦 Setup
1. Clone repo
2. Install dependencies (frontend & backend)
3. Add `.env` file
4. Run backend and frontend
